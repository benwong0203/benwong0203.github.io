English

Support

This is the shared support page for games published by Ben Wong. Future games will use the same page, so the address does not need to change.

Play progress is usually stored on your device. Unless a particular game says otherwise, there is no account and no in-app purchase.

If you need help or want to report a problem, email benben3445@hotmail.com.

If you can, please include the game name, your device model, system version, and the TestFlight or App Store build number.
