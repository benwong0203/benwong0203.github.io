Support

This is the shared support page for games published by Ben Wong. Future games will use the same page, so the address does not need to change.

Games currently listed:

  • Puppy House (Traditional Chinese: 小狗之家：狗狗照顧模擬器; Japanese: パピーハウス：犬のお世話シミュレーター)
